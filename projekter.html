Route Finder

ASP.NET Core • JavaScript • Leaflet.js • Azure

En webapp til at generere cirkulære ruter til løb, cykling og gåture. Bygget fordi jeg ville udforske nye ruter i mit nabolag uden at betale for premium ruteplanningsprogrammer.

Funktioner inkluderer:

  • Klik for at vælge lokation eller brug din nuværende position
  • Generer cirkulære ruter fra 1-50km
  • Forskellige aktivitetstyper (gå, løb, cykling, kørsel)
  • Download ruter som GPX, GeoJSON eller JSON

StateForge

Under udvikling

ASP.NET Core • .NET 10 • EF Core • SQL Server • Azure Service Bus • Polly • OpenTelemetry • SignalR • .NET Aspire

En reconciliation engine, der holder systemer i sync, og beviser, at de faktisk er det. De fleste integrationsværktøjer flytter data og håber, det nåede frem. StateForge deler det op i to spor: en hurtig, optimistisk sync-sti og en uafhængig verifikationssti, der bagefter tjekker, om synkroniseringen faktisk lykkedes, og reparerer eller flagger afvigelser.

Min måde at udforske robuste integrationer på: Azure Service Bus til messaging, Polly til resilience, OpenTelemetry og Serilog til observability og Testcontainers til integrationstests, orkestreret lokalt med .NET Aspire på .NET 10.

Ikke offentligt endnu. Repoet deles, når fundamentet er på plads.
